# 10 дел

Отдельный чёрно-белый сайт: 10 редактируемых клеток, отметки выполнения и прогресс
в процентах. Каждое выполненное дело даёт 10%. Пустая клетка открывает добавление
дела; заполненная переключает выполнение. Карандаш изменяет название, корзина
удаляет дело после подтверждения. Сброс снимает только отметки.

Данные сохраняются в localStorage этого браузера и не отправляются на сервер.
На другом устройстве список будет отдельным. При очистке данных сайта список
удалится. С наступлением нового дня отметки автоматически не сбрасываются.

## Запуск

Откройте `index.html` или запустите из папки проекта:

```sh
python3 -m http.server 8080
```

Зависимости и сборка не нужны. Для Vercel выберите Other, без команды сборки,
корневая папка проекта. Для GitHub Pages — Deploy from a branch → main → / (root).

## Telegram-бот

В папке [`bot`](bot/README.md) — Node.js-бот с кнопками «Дела», «Прогресс» и
«Прогресс за неделю». Пошаговый запуск и проверка описаны в его инструкции.
Токен и ID владельца заполняются локально в `bot/.env`, который исключён из Git.
Списки сайта и бота независимы. Статический сайт на Vercel не запускает процесс бота.
