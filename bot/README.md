# 🤍 Telegram-бот «10 дел»

Node.js-бот с тремя кнопками: **📝 Дела**, **📊 Прогресс**,
**🗓 Прогресс за неделю**. Тон дружелюбный, интерфейс на русском.

Каждому пользователю доступно 10 собственных клеток. Нажмите пустую, отправьте
название дела и откройте карточку. В ней есть кнопки **✅ Завершить**,
**↩️ Отменить выполнение**, **✏️ Изменить** и **🗑 Удалить**.

## 1. Установить Node.js

Установите актуальную LTS-версию с https://nodejs.org (нужен Node.js 20 или новее).
Проверьте в терминале:

```sh
node --version
npm --version
```

## 2. Скачать проект и установить зависимости

```sh
git clone https://github.com/minullinunus-stack/tracker.git
cd tracker/bot
npm ci
```

Если проект уже скачан, откройте терминал в его папке `bot` и выполните `npm ci`.

## 3. Создать своего бота и получить ID

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Задайте имя и свободный username, оканчивающийся на `bot`.
3. Сохраните выданный токен локально. В чат, скриншоты и GitHub его не отправляйте.
4. Откройте **@userinfobot**, отправьте `/start` и запишите свой числовой ID.

Используйте отдельного бота трекера: бот «Хатм» уже работает через вебхук.

## 4. Заполнить локальный `.env`

В папке `bot` скопируйте `.env.example` в `.env`.

Linux / macOS:

```sh
cp .env.example .env
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
notepad .env
```

Откройте `.env` текстовым редактором и заполните:

```dotenv
BOT_TOKEN=токен_из_BotFather
OWNER_ID=ваш_числовой_ID
TIMEZONE=Europe/Moscow
```

Примеры выше — обозначения, а не действующие значения. Реальные токен и ID
храните только в `bot/.env`. Этот файл исключён из Git; в репозитории есть
только пустой `.env.example`. `TIMEZONE` задаёт границу дня для всех пользователей.

## 5. Проверить без токена

Из папки `bot`:

```sh
npm test
```

Тесты подменяют Telegram API и используют временную базу. Проверяются все
10 клеток, создание и редактирование, завершение и отмена, удаление,
сохранение после перезапуска, изоляция пользователей, граница дня в Москве,
недельная история и доступ владельца. Сеть и настоящий токен не нужны.

## 6. Запустить

```sh
npm start
```

При успешном подключении появится сообщение «🤍 Трекер запущен».
Оставьте терминал открытым. Для остановки нажмите `Ctrl+C`.

## 7. Проверить в Telegram

Пишите боту в **личном чате**:

1. `/start` — приветствие и три кнопки.
2. **📝 Дела** → **➕ 1. Добавить дело** → отправьте «Прочитать 10 страниц».
3. **Открыть дело** → **✅ Завершить**.
4. **📊 Прогресс** — должно быть **10%**, 1 из 10.
5. **🗓 Прогресс за неделю** — сегодня 10%, остальные дни без отметок — 0%.
6. Откройте первое дело → **↩️ Отменить выполнение** — сегодня станет 0%.
7. Проверьте изменение текста, затем удаление с подтверждением.
8. Остановите и снова запустите бот: сохранённые дела должны остаться.
9. `/stats` от владельца показывает количество пользователей; другим отказывает.

Другие команды: `/tasks`, `/progress`, `/week`, `/help`, `/cancel`.

## Как считаются проценты

- Одно выполненное дело = **10%**, даже если остальные клетки ещё пусты.
- После полуночи по `TIMEZONE` отметки нового дня — 0%, названия дел остаются.
- Недельный отчёт: сегодня и 6 предыдущих календарных дней. День без отметок — 0%.
- Средний процент недели — выполненные дела / 70 × 100, с округлением.
- Удаление снимает сегодняшнюю отметку; прошлые дни не переписываются.
- Бот и сайт имеют **отдельные списки**. Синхронизации с браузером нет.

## Где сохраняются данные

Локально в `bot/storage/tasks.json`, файл создаётся автоматически и исключён из
Git. Для резервной копии остановите бот и скопируйте папку `storage` в безопасное
место. Не удаляйте её при обновлении. Запускайте только один экземпляр бота с этой
базой. Список пользователей и их дела не публикуйте.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Просит заполнить `.env` | Файл находится именно в `bot/.env`; имя не `.env.txt`; ID состоит из цифр |
| Не подключается к Telegram | Правильность токена, доступ к `api.telegram.org`, отсутствие второго процесса с тем же токеном |
| Бот молчит в группе | Бот работает в личных чатах, чтобы не раскрывать чужие дела |
| Не сохраняются дела | Права записи в `bot/storage`, свободное место; проверьте сообщение в терминале |
| Повреждена база | Сохраните файл и восстановите резервную копию; бот не перезаписывает повреждённый JSON автоматически |
| Ответы прекратились | Терминал закрыт или компьютер выключен; запустите `npm start` снова |

## Постоянный запуск

Для работы 24/7 нужен постоянно работающий сервер с Node.js и постоянным диском
для папки `storage`. На нём выполните те же шаги и настройте запуск через
systemd или другой менеджер процессов. **Обычный статический деплой Vercel этого
бота не запускает**: там размещён только сайт. В `.vercelignore` папка `bot`
исключена из веб-публикации вместе с её настройками и базой.
